# Security policy

## Supported version

Security fixes are made on the latest version of the default branch.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues. Use GitHub's private security advisory feature for this repository, including:

- a clear description of the issue and affected component;
- steps to reproduce or a proof of concept;
- potential impact; and
- any suggested mitigation.

Bonk can access the host Docker daemon when deployed. Reports involving authentication, authorization, repository handling, environment-variable exposure, Docker socket access, container isolation, or dependency supply-chain risks are especially important.

Please allow maintainers a reasonable opportunity to investigate and release a fix before public disclosure.
